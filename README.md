## 📖 Descripción

**Kharla Piano iX-300** es un sintetizador de piano virtual desarrollado 100% en tecnologías web. Permite tocar piano directamente desde el navegador utilizando el teclado en pantalla, el teclado de la computadora o un piano físico conectado vía **USB MIDI**. 

Incluye **8 tipos de piano** diferentes, control de volumen, resonancia (reverb) y funciona como **Progressive Web App (PWA)**, lo que significa que puedes instalarlo en tu computadora o dispositivo móvil y usarlo **sin conexión a internet**.

> Desarrollado por **Kharla Web Solution** 🎵

---

## ✨ Características

- 🎹 **Teclado virtual de 61 teclas** (5 octavas, desde C2 hasta C7)
- 🎛️ **8 tipos de piano** con síntesis de audio en tiempo real:
  - Grand Acoustic
  - Bright Piano
  - Warm Piano
  - Electric (Rhodes)
  - Upright Piano
  - Honky Tonk
  - Synth Pad Piano
  - Harpsichord (Clavicémbalo)
- 🔌 **Soporte Web MIDI** para pianos físicos USB (entrada y salida)
- 🎚️ **Control de Volumen Master** y **Resonancia (Reverb)** ajustables
-  **Pedal de sustain** compatible (MIDI CC 64)
-  **PWA instalable** - úsalo offline como una app nativa
- 🖥️ **Diseño responsive** adaptable a diferentes tamaños de pantalla
-  **Sin dependencias externas** - HTML, CSS y JavaScript puro
